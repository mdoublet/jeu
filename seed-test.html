🧪 Générateur d'archive de test

Crée une archive « comme si » une partie venait de se terminer, pour tester le diaporama. Utilise les équipes de votre configuration actuelle, réutilise les vraies images archivées et votre configuration (étapes, anecdotes, villes…).
📽️ Ouvrir le diaporama
Notes
• Les données sont écrites sous un nouveau libellé d'archive — vos vraies archives ne sont pas touchées.
• Pour supprimer cette archive de test ensuite : onglet Archives → Supprimer les archives (attention, cela efface toutes les archives), ou supprimez les lignes portant ce libellé dans Supabase.
• Les images sont copiées depuis des photos déjà archivées (ou, à défaut, les photos en cours).
